# FlowForge frontend

## Build
- Define the dark developer-tool design system in global CSS.
- Add reusable navigation, job, worker, queue, chart, modal, details, and assistant components.
- Create dashboard, jobs, workers, queues, analytics, settings, and job-detail pages.
- Add isolated demo data and a REST API service prepared for the existing Express endpoints.
- Verify desktop and mobile layouts, navigation, filters, job creation feedback, and assistant interactions.

## Technical notes
- Use the project’s TanStack Router (the supported React router here) with standard React and CSS.
- Keep all data client-side placeholders; no backend, database, or authentication changes.
